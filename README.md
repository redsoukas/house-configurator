# house-configurator

Configurator υλικών για το Διαμέρισμα 1.4 (74 τ.μ.).

- `index.html`: 2D configurator πάνω στα φωτορεαλιστικά renders (δάπεδα, πλακάκια, deck, ντουλάπια, πάγκος, τοίχοι)
- `3d.html`: διαδραστικό 3D μοντέλο (Three.js)
- `images/`: renders και κάτοψη

Static site χωρίς build step. Τοπικά: `python3 -m http.server` και άνοιγμα στο http://localhost:8000
